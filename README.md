# Lekekassa

Tre enkle spill for barn rundt 4 år. Instruksjonene leses høyt på norsk.

- **Fargelegg**: Velg fisk, fugl, bil eller sommerfugl og fargelegg. Trykk FERDIG, så svømmer, flyr eller kjører tegningen i «verdenen din».
- **Sorter**: Dra ting til riktig kurv: farger, former, eller dyr i vann og på land.
- **Ballonger**: Sprett ballongene med riktig farge før tiden går ut. Slå rekorden!

## Spill på iPad

1. Åpne spillets nettadresse i **Safari** på iPad.
2. Trykk **Del** → **Legg til på Hjem-skjerm**, og slå på **Åpne som nettapp**.
3. Åpne spillet én gang med internett. Etter det virker det også uten nett.

Lyd: Hvis iPaden står på lydløs, kan lydeffektene bli borte. Stemmen trenger en norsk stemme på iPaden (Innstillinger → Tilgjengelighet → Opplest innhold → Stemmer).

## Oppdatere

Endre filene, og øk `VERSION` i `sw.js` (f.eks. `v1` → `v2`).
